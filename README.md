## Repository Structure & Standards

Each project directory includes:

- **`README.md`**: Business context, data dictionary, key questions, methodology, and summary of findings.
- **`requirements.txt`**: Pinned dependencies needed to reproduce the project environment.
- **`data/`**: Raw and processed datasets, or clear source links if files are too large to include.
- **`notebooks/`**: Jupyter notebooks with exploratory analysis, narrative commentary, and visualizations.
- **`src/`**: Reusable, documented Python scripts and modules (cleaning, analysis, plotting functions) following PEP 8 with docstrings and descriptive naming.
- **`outputs/`**: Exported charts, tables, and reports.

## Getting Started

To run these projects locally:

1. **Clone the repository:**
   ```bash
   git clone https://github.com/tmwilken/Python-Projects-Portfolio.git
   cd Python-Projects-Portfolio
   ```

2. **Create and activate a virtual environment:**
   ```bash
   python -m venv venv
   source venv/bin/activate      # macOS/Linux
   venv\Scripts\activate         # Windows
   ```

3. **Install dependencies:**
   Navigate to the specific project folder (e.g., `cd Customer-Churn-Analysis`) and run:
   ```bash
   pip install -r requirements.txt
   ```

4. **Run the project:**
   Launch Jupyter and open the notebook, or run the scripts directly:
   ```bash
   jupyter notebook
   # or
   python src/main.py
   ```
